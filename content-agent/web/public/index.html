📋 Pipeline 8 bước — xem chi tiết ▸
1
🔍 Research
Phân tích search intent (Informational / Commercial / Transactional). Xác định đối tượng mục tiêu, keyword phụ, câu hỏi cần trả lời, key points cần cover. Nếu RAG bật → query Knowledge Base bổ sung context.
2
📝 Outline
Tạo dàn ý chi tiết: tiêu đề đề xuất, meta description SEO, cấu trúc H2 → H3 với key points từng phần, số từ ước tính mỗi section, danh sách SEO keywords cần tích hợp.
3
✍️ Content
Viết bài HTML hoàn chỉnh theo dàn ý. Viết từng section riêng biệt, tích hợp keyword tự nhiên. Output là HTML markup (heading, paragraph, list, table). Có thể chỉnh sửa nội dung trước khi tiếp tục.
4
📊 SEO Optimize
Tối ưu kỹ thuật SEO: title tag (50-60 ký tự), meta description (150-160 ký tự), keyword density 1.0-1.5%, keyword trong 100 từ đầu, alt text ảnh, schema markup. KHÔNG viết lại nội dung.
5
🧑‍💼 QC / Humanize
Xóa dấu vết AI: tìm và xóa từ cấm, phá bullet point thừa, đa dạng độ dài câu, thêm quan điểm riêng. Chấm Humanness Score /100. Decision: PUBLISH (≥76) | REVIEW (60-75) | REWRITE (<60).
6+7
🖼️ Thumbnail + 🎨 Section Images song song
Thumbnail: ảnh đại diện 1200x630 bằng AI, hỗ trợ reference image + style transfer. Section Images: ảnh minh họa evocative/cinematic cho từng section (tối đa 3), không phải infographic hay diagram. Có thể regenerate từng ảnh.
8
🚀 Publish
Hiển thị preview + báo cáo (SEO score, humanness score, số từ, ảnh). Chờ xác nhận → đăng lên WordPress / Shopify / Haravan. Không publish khi humanness < 76.

2 📝 Outline Tạo dàn ý H2/H3, meta description Chờ
3 ✍️ Content Viết bài HTML chi tiết theo dàn ý Chờ
4 📊 SEO Optimize Tối ưu keyword, title, meta, schema Chờ
5 🧑‍💼 QC / Humanize Xóa dấu vết AI, chấm humanness score Chờ
6 🖼️ Thumbnail Tạo ảnh đại diện bằng AI Chờ
